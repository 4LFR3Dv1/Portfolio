## Renderer authority boundary

The first physical prototype established that Astro could render the accepted R1 state, but it also exposed a boundary error: reconstructing Registry and Governance from inside an Astro renderer would make presentation an institutional reader.

R2.1 therefore closes the physical path as:

```text
canonical R1 manifests
        ↓
privileged prebuild materializer
src/editorial/renderer-input.ts
        ↓
bounded AcceptedRendererInput
        ↓
build-only generated JSON
        ↓
Astro renderer
        ↓
HTML
```

The generated input contains only accepted distributed pages, public Editorial Documents, Core Surface DTOs, the Publication Shell Plan, completion identifiers and the Distribution digest. It excludes omitted document decisions, governance rationale, private semantic source and the Evidence corpus.

`editorial-shell/src/generated/` is ignored by Git. The generated JSON is derived build state, never a new authority.
