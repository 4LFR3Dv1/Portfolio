# R2.2 — Distribution Emission

Status: **MATERIALIZED / AWAITING DUAL CI WITNESS**

Baseline: `main@4c55124624c332fb9071dfd1033861a6778111f6`

R2.2 turns the accepted R1.7 Distribution Bundle into physical crawler/search artifacts and physical page metadata inside the isolated Astro shell. It does not activate those outputs in production.

## 1. Authority direction

```text
R1.7 Distribution Bundle
        ↓
R2.1 bounded renderer input
        ↓
R2.2 distribution emission
        ↓
Astro static output
```

The emitter cannot discover Records, infer routes, reconstruct Governance or pull omitted semantic content. If an item is absent from the accepted distribution state, R2.2 cannot make it crawlable or searchable.

## 2. Physical metadata

Each of the 18 canonical HTML pages now receives metadata from the exact accepted metadata entry for its canonical path:

```text
title
description
robots=index,follow
canonical
hreflang
```

The current accepted state contains 9 bilingual hreflang clusters and 18 unique language links. `x-default` is not inferred.

No metadata fallback is allowed. Missing or mismatched metadata aborts the build.

## 3. Physical artifacts

R2.2 emits exactly four static artifacts:

```text
/sitemap.xml
/en/rss.xml
/pt-br/rss.xml
/search-index.json
```

The sitemap contains exactly 18 accepted canonical pages. It contains no inferred `lastmod`, `priority` or `changefreq` values.

Both RSS feeds are physically valid envelopes with zero items because no chronological `representation.publication` authority exists yet. Git history and filesystem timestamps are not used as publication chronology.

The search index contains exactly six semantic System documents:

```text
VIRA             EN / PT-BR
XS Wallet        EN / PT-BR
SNE-OS           EN / PT-BR
```

`Transactional Support Bot` and `Foundry Pay` remain absent because their sanitized semantic authority is still unavailable.

## 4. Renderer boundary

The privileged prebuild materializer reconstructs the accepted institutional state once and produces a bounded public input. R2.2 adds the already-public distribution bundle and deterministic emitted artifact payloads to that input.

Astro receives no additional institutional authority:

```text
Registry direct read     0
Evidence direct read     0
Governance direct read   0
private semantic input   0
```

## 5. Deployment remains unchanged

R2.2 does not replace the production sitemap and does not alter Vercel or the root Vite build.

```text
physical Astro sitemap exists      true
physical Astro RSS exists          true
physical Astro search index exists true
physical canonical metadata exists true

production sitemap replaced        false
Astro activated in production      false
vercel.json changed                false
root build changed                 false
deployed runtime changed           false
```

The production React/Vite application remains authoritative until the explicit cutover sequence.

## 6. Acceptance

R2.2 closes only when both repository Verify and Editorial Shell Build pass against the same materialized state and the physical shell verifier proves:

- 18 canonical HTML pages remain present;
- 18 sitemap entries are emitted;
- 2 RSS feeds are emitted with 0 items;
- 6 search entries are emitted;
- canonical/robots/hreflang metadata exists on representative pages;
- no `x-default`, `lastmod`, `priority`, `changefreq` or language fallback is invented;
- omitted/sanitized documents do not enter search;
- R2.3 legacy pages and R2.4 redirects remain inactive;
- production deployment remains unchanged.
