# R2.5 — Static Runtime Commissioning

Status: **COMPLETE / DUAL CI WITNESSED**

Baseline: `main@d5f6f530effc411a718eae60dae613cc13b8a5a4`

R2.5 is the first cut that treats the future publication system as one physical local runtime rather than a set of individually verified artifacts.

It does not deploy the runtime publicly.

## 1. Commissioned composition

```text
accepted R1 state
      ↓
Astro static build
      ↓
18 canonical pages
4 historical preserved pages
4 compatibility handshake pages
404 + distribution artifacts + static assets
      +
bounded compatibility redirect adapter
      ↓
local commissioned HTTP runtime
```

The local runtime serves the exact `editorial-shell/dist` output and reuses the accepted R2.4 redirect adapter. It does not rediscover Registry, Evidence, governance, routes or language from HTTP requests.

The redirect witness covers all four legacy redirect sources in EN and PT, for eight physical `302` responses.

## 3. Header / HTML consistency

Canonical pages carry both their renderer-emitted metadata and runtime HTTP metadata derived from the same accepted distribution state:

```text
HTML <link rel="canonical">
HTTP Link: <...>; rel="canonical"
HTTP Content-Language
HTML robots=index,follow
HTTP X-Robots-Tag: index,follow
```

The physical campaign requires the HTTP canonical target to equal the canonical URL embedded in the HTML.

Historical and compatibility handshake pages remain explicitly non-canonical:

```text
HTML robots=noindex,follow
HTTP X-Robots-Tag: noindex,follow
HTTP Link canonical: absent
```

## 4. Content types

R2.5 makes content-type behavior explicit at the runtime boundary:

```text
HTML                  text/html; charset=utf-8
sitemap.xml           application/xml; charset=utf-8
RSS                    application/rss+xml; charset=utf-8
search-index.json      application/json; charset=utf-8
PDF                    application/pdf
CSS / JS / images      type-specific static MIME
```

Every response also receives `X-Content-Type-Options: nosniff` where static or redirect behavior is served.

## 5. Cache behavior

Semantic and compatibility surfaces are deliberately conservative during commissioning:

```text
canonical HTML
historical HTML
compatibility handshake HTML
redirect responses
distribution artifacts
non-fingerprinted static assets
404
      ↓
Cache-Control: no-store
```

Fingerprint-style `/_astro/*` assets, when present, are served as:

```text
Cache-Control: public, max-age=31536000, immutable
```

This is a commissioning contract, not yet a production CDN policy.

## 6. Fault injection

The local runtime exposes a commissioning-only fault hook that can remove an otherwise admitted canonical successor from the runtime-visible distributed set.

The physical witness removes `/pt-br/systems/vira` and proves:

```text
/_compat/redirect?from=/work/vira&lang=pt
      ↓
503
Location: absent
```

This demonstrates fail-closed behavior in the same integrated runtime that serves the static site.

## 7. Assets and 404

The verifier reconstructs the complete physical `dist` file graph, subtracts the 26 HTML route files, 404 and the four distribution artifacts, and requests every remaining static asset through the commissioned server.

The accepted physical build contains two remaining static assets. Both return `200`, carry `nosniff`, have explicit content types and follow the required cache policy. PDF evidence/publication assets resolve as `application/pdf`.

Unknown extensionless routes do not fall back to Home. They return the physical `404.html` with HTTP 404 and `noindex,follow`.

## 8. Deployment boundary

R2.5 remains local-only.

```text

vercel.json                 unchanged
production React SPA        authoritative
Astro production runtime    inactive
production redirects        inactive
public sitemap replacement  inactive
```

The commissioned runtime is a physical readiness witness, not cutover authorization.
