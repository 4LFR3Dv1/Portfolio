# R1.2 — Projection Engine

Status: **MATERIALIZED / AWAITING CI WITNESS**

Baseline: `main@3269521c20027ac1f4a80950458d705a58fa7f42`

Preconditions:

```text
R0_EFFECTIVE_COMPLETE=true
R1_PRE_COMPLETE=true
R1_0_COMPLETE=true
R1_1_COMPLETE=true
```

R1.2 materializes the boundary between canonical editorial state and what a public consumer may receive.

The central rule is:

```text
canonical state
    !=
public projection
```

A renderer never reads the Record Registry and decides for itself what to show. It receives only a projection decision produced after current Record lineage, governance and route/language identity have already resolved.

## 1. Projection is not authority

Projection consumes authority from earlier contracts. It does not create it.

```text
Record Registry
      +
current disclosure
      +
current route/language identity
      +
optional maturity projection
      ↓
Projection Engine
      ↓
omitted | redirect | projected DTO
```

R1.2 may not mint Records, infer disclosure, infer maturity, invent a route, invent language fallback or reinterpret a private Record as public.

## 2. Record Birth does not imply projection

R1.1 created 28 `knowledge.system` Records.

Those Births establish durable identity. They do not establish public eligibility.

At the R1.2 baseline no R1 disclosure authority, route binding or language realization has yet been admitted for the newly born current heads. Therefore the new editorial substrate currently has:

```text
born System Records             28
current public projections       0
```

This does not remove anything from the deployed legacy Portfolio because framework cutover has not occurred. It means only that the new R1 runtime refuses to manufacture public state from Birth alone.

## 3. Public gates

A target can reach a public projection only when all relevant gates resolve:

```text
current target lifecycle = active | archived
AND
current disclosure uniquely classified
AND
visibility.record = public
AND
disclosure != withheld
AND
route/language identity resolved
AND
resolved route points to exact current target head
```

The engine preserves fail-closed outcomes rather than replacing them with a permissive default.

## 4. Omission is an explicit state

R1.2 distinguishes why a target cannot currently become public projection. Examples include:

```text
target-lifecycle-ineligible
disclosure-unclassified
disclosure-conflict
record-private
record-withheld
route-unresolved
route-head-unavailable
language-unavailable
route-conflict
route-target-mismatch
route-invalid-canonical-path
```

These reasons are diagnostic projection state. They are not new ontology, Claims or Evidence.

## 5. Alias resolution does not duplicate documents

A valid R0.7 alias may resolve the same Record and language as a canonical route.

R1.2 therefore produces:

```text
redirect
```

for alias resolution rather than creating another projected document with duplicate canonical identity.

HTTP status policy remains a later runtime concern; R1.2 freezes only the semantic redirect intent and canonical destination.

## 6. The public DTO is bounded

The first R1.2 public Record projection DTO contains only bounded public-facing metadata:

```text
exact pinned target identity
RecordKind
eligible lifecycle
language
canonical path
canonical URL
disclosure mode
source availability classification
Evidence availability classification
maturity projection state
content policy
```

It intentionally contains no:

```text
canonical semantic payload
governance rationale
registry grounding provenance
identity-decision notes
source locator
private Evidence material
```

R1.2 therefore cannot leak private material merely because some later renderer accidentally receives the authoritative Registry object.

## 7. Content is not yet materialized by projection

R1.2 does not render or transport canonical Record payloads.

Every projected DTO carries:

```text
payloadIncluded=false
runtimeSanitizationAllowed=false
```

This is deliberate.

R1.5 — Editorial Document Runtime owns the later problem of turning an admitted language realization into a document projection. R1.2 owns only the authorization and bounded projection envelope.

## 8. Metadata-only is structurally payload-free

For:

```text
disclosure=metadata-only
```

R1.2 never includes the canonical semantic payload.

A future document runtime therefore cannot accidentally render hidden body content from a metadata-only projection because the R1.2 DTO does not carry it.

## 9. Sanitized is admission, not runtime redaction

R0.6 already froze that `sanitized` means the admitted target revision is itself the bounded public-safe form.

R1.2 preserves that rule.

It never performs:

```text
private payload
   ↓ automatic redaction
public payload
```

There is no runtime sanitization engine in R1.2.

## 10. Maturity remains independent

Maturity is projected only as current governance state:

```text
not-applicable
unclassified
conflict
classified(stage)
```

It does not gate exposure.

Therefore all remain structurally possible when disclosure is valid:

```text
public + maturity unclassified
public + maturity conflict
public + research
public + production
```

R1.2 never turns `production` into Evidence and never turns missing maturity into privacy.

## 11. Route and language remain upstream identities

R1.2 consumes the R0.7 `RouteIdentityResolution` result.

It does not yet create the runtime registries that produce that result. Those are owned by later R1 cuts.

A `resolved` route already means that the exact current Record head possesses the requested language realization. If R0.7 reports `language-unavailable`, R1.2 preserves that state and omits the target rather than falling back to another language.

## 12. Projection is deterministic

Given the same:

```text
current target head
current disclosure projection
current maturity projection
current route/language resolution
```

R1.2 returns the same projection decision.

It does not inspect timestamps, file ordering, latest Git activity, browser state or UI preference.

No latest-wins repair exists.

## 13. Runtime boundary

R1.2 remains build-time editorial substrate.

```text

framework cutover           false
public UI changed           false
deployed runtime semantics  false
```

The current React/Vite public surface remains untouched.
