# R2.3 — Legacy Preservation Runtime

Status: **MATERIALIZED / AWAITING DUAL CI WITNESS**

Baseline: `main@ab9564a065d5bbd721e242a3b98e47a31fa2f80f`

R2.3 gives the isolated Astro shell a bounded historical runtime for the four public URLs that R1.8 explicitly forbids from being redirected yet.

It does not convert old Portfolio objects into new Records. It preserves the public meaning of the old routes while keeping them outside canonical editorial distribution.

## 1. Preserved routes

Exactly four routes are admitted by the R1.8 compatibility boundary:

```text
/architecture
/work/agentic-systems
/work/transactional-support-bot
/work/verify-systems
```

Their authority direction is:

```text
R0.0 frozen legacy source blobs
          +
R1.8 compatibility disposition
          +
R2.0 shell plan
          ↓
bounded LegacyPreservationState
          ↓
Astro historical renderer
```

The renderer cannot discover another legacy page from `projects.ts`, infer a successor or mint a Record.

## 2. Frozen source integrity

The historical content is reconstructed only while the exact R0.0 source blobs remain intact:

```text
src/app/data/projects.ts
  df6fe680cd96ede69b3ff7e1f0a6b3b498b16c9f

src/app/data/architecture.ts
  377fd24faab1be39ba135b8d1cd62379e97f403a
```

R2.3 computes Git blob SHA-1 over those source files during institutional materialization. Any drift fails closed instead of silently changing what a historical URL means.

This preserves semantic source identity without requiring the new renderer to execute the old React components.

## 7. Legacy language state

These routes remain shared-path bilingual representations. They do not become `/en/*` or `/pt-br/*` routes merely because the Astro shell can render both languages.

The old client-state contract remains:

```text
localStorage["portfolio-language"]
  en → English
  pt → Portuguese
missing → English
```

No `Accept-Language`, browser-locale or cross-language inference is introduced.

The HTML contains both frozen language realizations and the tiny compatibility script selects the visible realization from the old storage key. With JavaScript unavailable, English remains the deterministic default.

## 8. Distribution quarantine

Legacy preservation is availability, not canonical re-publication.

Every preserved page therefore emits:

```text
robots = noindex,follow
canonical = absent
hreflang = absent
```

and remains absent from:

```text
/sitemap.xml
/en/rss.xml
/pt-br/rss.xml
/search-index.json
```

This preserves the URL for existing users and inbound links without creating a second manual public-distribution registry beside R1.7.
