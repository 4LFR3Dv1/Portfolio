R1.5 materializes the renderer-neutral document boundary between public projection authority and future HTML/UI rendering.

The core relation is:

```text
Public Record Projection
        +
exact Language Realization
        ↓
Editorial Document DTO
```

and never:

```text
Record → React component
Record → Markdown file by convention
route → content inference
renderer → semantic authority
```

## 1. A document is not a Record

The document DTO is a derived consumer artifact.

It does not mint or replace:

```text
RecordId
RevisionId
PayloadDigest
RouteBinding
LanguageBinding
Disclosure authority
Evidence authority
```

Its `targetRef` remains the exact pinned Record revision already admitted by the projection boundary.

## 2. A document requires a public projection first

R1.5 never bypasses R1.2.

If the upstream decision is:

```text
omitted
```

then no document exists.

If the upstream decision is:

```text
redirect
```

R1.5 preserves redirect semantics and does not manufacture a document for the alias request.

Only `projected` input may become an Editorial Document DTO.

## 3. Full semantic content requires the exact language realization

For `full` disclosure, the document runtime resolves a language realization matching all three coordinates:

```text
RecordId
RevisionId
LanguageTag
```

A realization for the same Record but an older revision is insufficient.
A realization for the exact revision but another language is insufficient.

No canonical-language fallback occurs here because R1.4 already forbids it.

## 4. Current executable adapter: knowledge.system

R1.5 v0 materializes the first explicit content adapter for the only semantic kind currently Born and language-admitted by R1.1/R1.4:

```text
knowledge.system
```

Its renderer-neutral content form is:

```text
name
summary
thesis
```

The values come from the exact admitted R1.4 language realization.

The document does not reopen `projects.ts`, crawl GitHub, reinterpret README text or infer richer copy.

Other RecordKinds require explicit future adapters rather than being coerced through a System-shaped document.

## 5. Metadata-only disclosure carries no semantic payload

When R1.2 produces a public projection with:

```text
disclosure = metadata-only
```

R1.5 may materialize only the bounded envelope already public under projection authority:

```text
targetRef
kind
lifecycle
language
canonical route
public disclosure axes
maturity projection
```

It MUST NOT include `name`, `summary`, `thesis` or any other semantic Record payload.

This prevents `metadata-only` from becoming an accidental synonym for `full`.

## 6. Sanitized disclosure is not runtime redaction

The most important negative rule is:

```text
sanitized
    !=
load canonical private payload
    +
redact it during rendering
```

R1.2 already freezes `runtimeSanitizationAllowed=false`.

Therefore, when a projected Record is marked `sanitized` but no independently admitted disclosure-safe content authority exists, R1.5 returns:

```text
sanitized-content-authority-unavailable
```

It does not transform canonical System payload at runtime.

A future sanitized public case study should be represented by an independently admitted public representation or other explicit disclosure-safe realization, not by deleting sensitive fields from a private source during page rendering.

## 7. Realization integrity is carried forward

For full documents R1.5 preserves:

```text
realization role
realization digest
translatedFrom
```

from R1.4.

That digest remains integrity metadata for the exact language realization. It does not become a new Record identity or truth claim.

## 8. DTO immutability

The materialized DTO is frozen as a consumer value.

The renderer may format it but cannot mutate the DTO into a different semantic state and then treat that mutation as admitted editorial truth.

This is an execution property, not a replacement for R0 identity rules.

## 9. No document renderer or framework cutover yet

R1.5 does not install or activate the Astro shell.

It does not introduce:

```text
Astro pages
Markdown/MDX authority
static HTML generation
RSS
sitemap generation
search indexing
new public UI
framework cutover
```

Those remain later R1 responsibilities.

The current React/Vite deployment continues unchanged.
